# 🎬 CineAI – Your Smart Movie Guide

# CineAI is a modern movie discovery web application that allows users to search for movies and instantly view detailed information such as storyline, cast, ratings, and streaming platform availability. Built with a clean OTT-style UI, the app fetches real-time movie data and displays high-quality posters and cast images to help users decide what to watch.

# Tech Stack: React, Vite, TypeScript, Tailwind CSS, OMDb API, TMDB API
